1. Introduction & Objectifs

1.1 Contexte

Les maladies infectieuses et chroniques représentent un défi majeur pour les systèmes de santé. La détection précoce et la surveillance épidémiologique sont essentielles pour une réponse efficace.

Ce projet propose un système Big Data intelligent capable de :

  • Détecter automatiquement les maladies à partir des symptômes
  • Surveiller en temps réel la propagation géographique
  • Prédire les diagnostics grâce au Machine Learning distribué

1.2 Problématique

Comment exploiter les technologies Big Data pour construire un système de détection de maladies à grande échelle, capable de traiter plus d'un million de dossiers patients en temps quasi-réel ?

1.3 Objectifs Spécifiques

6. Apache Kafka — Streaming

6.1 Principe

Kafka assure l'ingestion temps réel des données patients. Le Producer lit le CSV et envoie des messages JSON. Le Consumer les traite et les stocke.

df_final.csv ──▶ [PRODUCER] ──▶ kafka_messages.json ──▶ [CONSUMER] ──▶ MongoDB Atlas 200 messages/session traitement stockage NoSQL

10. Installation & Exécution

10.1 Prérequis

  • Python 3.9 ou supérieur
  • Compte Databricks Community Edition
  • Connexion Internet (MongoDB Atlas, OpenStreetMap)

10.2 Lancer le Dashboard Streamlit

  1. Ouvrir un terminal dans le dossier du projet
  2. Installer les dépendances :
    pip install -r streamlit_app/requirements.txt
  3. Lancer l'application :
    streamlit run streamlit_app/Accueil.py
  4. Ouvrir le navigateur → http://localhost:8501

10.3 Exécuter Databricks (Notebooks)

  1. Se connecter à Databricks Community Edition
  2. Uploader df_final.csv via Catalog > Add Data > Upload Files
  3. Créer les notebooks et copier le code depuis databricks/
  4. Exécuter dans l'ordre : 01 → 02 → 03 → 04 → 05
  5. Télécharger model_trained.pkl depuis FileStore
  6. Placer dans streamlit_app/model/model_trained.pkl

10.4 Tester Kafka

# Terminal 1 : Lancer le Producer python kafka/producer.py # Terminal 2 : Lancer le Consumer python kafka/consumer.py

  • ✅ Stockage NoSQL avec MongoDB Atlas
